# PioOne V42.3 — Worker Factory als eigener Tab

Digital Workers (DW) Navigation:

1. DWs (Katalog und Worker-Details)
2. DW Organisations (digitale Organisation)
3. **Worker Factory** (Worker-Definitionen, Versionen, Draft, Publish, Retire)
4. DW Settings (Worker-Zuordnungen und digitale Stellen)

Worker Factory wurde aus DW Settings entfernt; sie verwendet weiterhin dieselbe WorkerRegistrySettings-Komponente und denselben lokalen Demo-Datenspeicher. Der "Worker erstellen"-Button im Katalog öffnet nun Worker Factory. Es werden keine produktiven Worker gestartet oder deployed.

Basis: V42.2. Die bestehende Explorer-Ansicht und die Landingpage bleiben erhalten.

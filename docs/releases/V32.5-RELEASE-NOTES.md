# PioOne V32.5 — Official PioVation branding

Based on V32.4. Only the existing PioVation company logo (`app/webui/public/logo.png`) is used as a brand logo on the landing page. The invented Sparkles brand icon has been removed from the header, footer and mini workspace preview; PioOne remains a plain-text product name. The hero-first / benefits / all-applications ordering from V32.4 is preserved. Original diagram and demo and Keycloak UI are preserved.

Start: `cd app/webui && npm install && npm run dev`.

This is a frontend prototype. Production deployment requires backend authorization and authentication configuration.

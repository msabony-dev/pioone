# PioOne V32.3 — Navigation & Landing Page fixes

- Communication remains a standalone sidebar module. Removed duplicate Communication submenu from **Mein Assistent** (DCOS). Access through the assistant is still possible via contextual features; it is no longer a duplicate navigation listing.
- Landing page DE/EN selection initializes from and writes to `pio19-language`, matching the application LanguageProvider.
- Closing CTA now calls `onLogin` for `Jetzt anmelden` / `Sign in now` (rather than redirecting to the demo).
- Removed dead `login` and `loginError` state.
- Removed global DCOS replacement in translations. Only exact `DCOS` label is displayed as `Mein Assistent` / `My Assistant`. Legitimate technical references to DCOS remain intact.
- Hero headline wraps at intermediate viewport sizes and is no longer forced to nowrap.
- Split some long landing-page markup into readable segments; further full Prettier/ESLint formatting is recommended once dependencies are available.

## Verification

The code changes concern the local React prototype. No production auth/permission guarantees are implied.
